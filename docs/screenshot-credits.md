To change a screenshot, edit the item's `screenshot` entry in `data/resources/catalog/catalog.json`. Pick a file under a free license, and use the 960px thumbnail address the Commons API returns (`prop=imageinfo&iiurlwidth=960`): Commons only serves standard thumbnail widths, and other widths answer with an error page.
