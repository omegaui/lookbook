# .agentic-coding

Working notes for AI coding agents that pick up this project.

| Path | What it is |
| --- | --- |
| `HANDOFF.md` | Current state, how to build and verify, decisions, pitfalls and open work. **Read it first.** |
| `design/` | The approved wireframe: the canvas link and a copy of its source |
| `scripts/` | Helpers for quick checks, builds, opening a page and screenshotting the app window |

Keep `HANDOFF.md` current: when you finish a piece of work or the user decides something, update the "State" and "Open work" sections in the same commit.
